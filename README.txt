Birthday Gift Website — Soumita

Open index.html in a browser. No server is required.

Flow:
1. Birthday screen with Blow the Candles button.
2. Candle blown screen with Next.
3. Accept gift: YES / NO.
4. Choose Your Gifts: letter / flowers / final surprise.
5. Letter contains the personalized birthday message.
6. Final screen includes I Wanna Be Yours by Arctic Monkeys.

Music:
The included MP3 is the user-provided file. The player seeks to 2:20 (140 seconds) before playing.

Note:
The two screenshot backgrounds supplied by the user are used for the first two stages. If separate candle-fire and extinguisher image assets are supplied later, they can be placed into the candle stage without changing the flow.
